VQSTing is a web-based software application used for operating and evaluating subjective tests of video quality.

To use the VQSTing system, please create an account and log in.

As a specialist, you can create and manage test sessions and check the statistics after each test. While creating tests, you have to set a password, which will be used by observers to start the evaluation. Each observer has to have their own account with filled profile information to participate in the test. The tests should be carried out under managed viewing conditions by a specialist who sets the session.
