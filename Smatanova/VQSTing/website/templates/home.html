VQSTing is a web-based software application used for operating and evaluating subjective tests of video quality.

Log in as an administrator to create and run tests.

A specialist creates a test session, copies the videos into its folders and then opens My test sessions → Group test. Up to four testers watch the same video on one monitor and vote side by side, each on their own keyboard or with the mouse. After the test the specialist exports the ratings as CSV.
